# ProjetPratique_Edacy
#  Recette API

Une API Node.js/Express avec MongoDB plus particuliérement la version cloud (Mongo Atlas) permettant aux utilisateurs de s'inscrire, se connecter, et gérer leurs recettes de cuisine (ajout, récupération, suppression, etc.).

##  Fonctionnalités

- ✅ Authentification JWT (inscription et connexion)
- ✅ Création de recettes avec image
- ✅ Récupération des recettes par utilisateur
- ✅ Suppression de recettes
- ✅ Middleware de protection des routes
- ✅ Stockage des images sur le serveur

---

##  Stack utilisée

- Node.js / Express
- MongoDB / Mongoose
- Multer (upload d'image)
- JSON Web Tokens (JWT)
- ReactJS (recette-frontend)
- Postman (pour tester l’API)

---
